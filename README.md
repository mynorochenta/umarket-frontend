# UMarket — Frontend

Marketplace universitario para compra y venta de artículos entre estudiantes.

**Estado: en desarrollo**

## Stack
- Next.js 16 (App Router) + React 19 + TypeScript
- Tailwind CSS v4
- Backend: API REST en Java + Spring Boot + MySQL — https://github.com/mynorochenta/UMarket

## Qué funciona
- Registro e inicio de sesión conectados al backend
- Feed de publicaciones y detalle de publicación desde la API
- Interfaz de favoritos, mensajes, perfil, búsqueda y notificaciones (con datos de prueba)
